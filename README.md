# AI-Generated vs Human-Written Text Classification with BERT and RoBERTa

Fine-tuning and comparing **BERT** (`bert-base-uncased`) and **RoBERTa** (`roberta-base`) to detect whether a text was written by a human or generated by an AI.

> Final Project (Tugas Akhir), Bachelor of Informatics, Telkom University, 2025.
> *Performance Evaluation of Fine-Tuned BERT and RoBERTa for AI-Generated and Human-Written Text Classification*

## Highlights

- Pretrained BERT and RoBERTa perform at roughly **random-guess level** (accuracy about 0.49 and 0.50) on this task without fine-tuning.
- After fine-tuning, **RoBERTa reaches 0.9918 accuracy / F1** and **BERT reaches 0.9803 accuracy / 0.9802 F1** on the held-out test set.
- RoBERTa outperforms BERT on every metric and is also more stable across runs (lower standard deviation).
- Fine-tuning RoBERTa was also faster in this setup (about 1h 12m vs 1h 38m per run).

## Dataset

- English Wikipedia article introductions, each available as a human-written and a machine-generated version (columns: `title`, `label`, `text`, `word_count`).
- Labels: `0` = human-written, `1` = AI-generated.
- After removing duplicates, the data is **balanced to 50,000 samples per class** (100,000 total).
- Split: **70% train / 15% validation / 15% test**, stratified by label (`random_state=42`). The notebook also checks that there is no text overlap between the splits.

## Method

1. **Preprocessing:** whitespace normalization and duplicate removal, then model-specific tokenization (max length 512, truncation and padding).
2. **Baseline:** evaluate the pretrained models with a freshly initialized classification head, before any training.
3. **Fine-tuning:** end-to-end training of the encoder plus a binary classification head, using Hugging Face `Trainer`.
4. **Model selection:** evaluate every 1,000 steps and keep the checkpoint with the best validation F1.
5. **Evaluation:** accuracy, precision, recall, and F1 (weighted) plus confusion matrices on the untouched test set.

### Training configuration (identical for both models)

| Parameter | Value |
|-----------|-------|
| Learning rate | 1e-5 |
| Per-device batch size | 8 (with gradient accumulation of 2) |
| Epochs | 2 |
| Max sequence length | 512 |
| Dropout | 0.1 (hidden and attention) |
| Weight decay | 0.01 |
| Warmup ratio | 0.1 |
| Precision | mixed precision (fp16) |

## Getting Started

The notebook was developed on Google Colab with a GPU.

```bash
# 1. Clone the repository
git clone https://github.com/<your-username>/<your-repo-name>.git
cd <your-repo-name>

# 2. (Optional) create a virtual environment
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Open the notebook
```

Before running, update the dataset path in the notebook (the original points to a Google Drive location) so it matches where you saved the CSV. Training both models at 512 tokens takes over an hour each on a Colab GPU, and a CUDA-capable GPU is strongly recommended.

## Limitations

- Evaluated on a **single dataset** (Wikipedia introductions), so results may not generalize to other domains or writing styles.
- Only BERT and RoBERTa were compared, with no ensembling, data augmentation, or other advanced techniques.
- Hyperparameters were chosen under hardware limitations rather than tuned extensively.

## Future Work

- Test on more diverse datasets and text domains.
- Compare additional architectures (for example DeBERTa or DistilBERT).
